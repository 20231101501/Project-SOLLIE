🔐 SAFETY FEATURES
══════════════════

🛡️ Three-Layer Protection:

Layer 1: WHITELIST SYSTEM
  → Only approved apps can be opened
  → Only safe directories can be accessed
  → Dangerous actions are blocked

Layer 2: APPROVAL MODE
  → Sol asks before EVERY action
  → You must click "Approve" to proceed
  → Actions can be denied at any time

Layer 3: ACTION LOGGING
  → Every action is recorded
  → View history in Settings
  → Review what was approved/denied

❓ FREQUENTLY ASKED QUESTIONS
═════════════════════════════

Q: Is this really free?
A: Yes! 100% free. No subscriptions, no hidden costs.

Q: Will this break my PC?
A: No. Sol has multiple safety layers and can't access
   system files or perform dangerous operations.

Q: Can I use this offline?
A: Yes! After downloading the AI model, everything runs locally.

Q: How much disk space do I need?
A: ~20GB total (model + files + overhead)

Q: Can I customize Sol's personality?
A: Absolutely! Edit config.json → "personality" field

Q: What if something goes wrong?
A: Check Settings → View Action Log to see what happened.
  Worst case: delete sol_memory.json and restart fresh.
