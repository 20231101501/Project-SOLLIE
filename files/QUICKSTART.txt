📋 CHECKLIST - Do these in order:

  ☐ 1. Extract Sol folder to your PC
  ☐ 2. Install dependencies
  ☐ 3. Setup LM Studio
  ☐ 4. Test everything
  ☐ 5. Launch Sol!


═══════════════════════════════════════════════════════════════

STEP 1: EXTRACT FILES
══════════════════════

1. Put the Sol folder somewhere easy like:
   C:\Users\YourName\Sol

2. You should see these files:
   • sol_gui.py
   • sol_core.py
   • config.json
   • setup.py
   • README.md


═══════════════════════════════════════════════════════════════

STEP 2: INSTALL DEPENDENCIES
═════════════════════════════

1. Open Command Prompt in the Sol folder:
   → Hold Shift + Right-click in folder
   → Click "Open PowerShell window here"

2. Run this command:
   
   python setup.py

3. Wait 2-5 minutes for installation

4. If you see "✓ SETUP COMPLETE!" → proceed to Step 3


═══════════════════════════════════════════════════════════════

STEP 3: SETUP LM STUDIO (THE AI BRAIN)
═══════════════════════════════════════

1. Download LM Studio:
   → Go to: https://lmstudio.ai/
   → Download Windows version
   → Install it

2. Download an AI model:
   → Open LM Studio
   → Click "Discover" tab (left side)
   → Search: "Llama-3.1-8B-Instruct"
   → Click the download button
   → Wait 10-20 minutes (it's ~5GB)

3. Start the Local Server:
   → Click "Local Server" tab (left side)
   → Select your downloaded model from dropdown
   → Click "Start Server" button
   → You should see: "Server running on http://localhost:1234"
   → KEEP LM STUDIO RUNNING!


═══════════════════════════════════════════════════════════════

STEP 4: TEST EVERYTHING
════════════════════════

1. In Command Prompt (in Sol folder), run:
   
   python test_sol.py

2. Check the results:
   ✓ All tests PASS? → You're ready!
   ✗ Some tests FAIL? → Check what failed and fix it

Common issues:
  • "Cannot connect to LM Studio"
    → Make sure LM Studio's server is running
  
  • "Module not found"
    → Run: python setup.py again


═══════════════════════════════════════════════════════════════

STEP 5: LAUNCH SOL! 🚀
═══════════════════════

Method A - Desktop Shortcut:
  → Double-click "Sol" icon on desktop

Method B - Command Line:
  → Open Command Prompt in Sol folder
   → Run: python sol_launcher.py

You should see Sol's chat window appear!


═══════════════════════════════════════════════════════════════

FIRST CONVERSATION
═══════════════════

Try these commands to test Sol:

1. "Hey Sol, introduce yourself"
   → Tests basic chat

2. "What can you do?"
   → Shows Sol's capabilities

3. "Open Notepad"
   → Tests PC control (will ask for approval)

4. "What's my system status?"
   → Shows CPU, RAM, disk usage


═══════════════════════════════════════════════════════════════

⚠️ IMPORTANT SAFETY NOTES
═══════════════════════════

• Sol will ALWAYS ask before doing anything
• You must click "Approve" for actions to execute
• Review the action description before approving
• All actions are logged (check Settings → View Action Log)


═══════════════════════════════════════════════════════════════

🛠️ TROUBLESHOOTING
══════════════════

Problem: "Sol is not responding"
Solution: Check if LM Studio server is running

Problem: "GUI won't open"
Solution: Run setup.py again, then restart

Problem: "Error connecting to localhost:1234"
Solution: 
  1. Open LM Studio
  2. Go to Local Server tab
  3. Make sure server is started

Problem: "Sol is too slow"
Solution: Use a smaller model (7B instead of 13B)
